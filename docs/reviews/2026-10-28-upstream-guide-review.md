# 2026-10-28 上游修正与安装 / 维护步骤复查

范围：文档和版本审阅元数据。本轮未向设备写入配置、模块或启动镜像，没有重启、停止服务或更改加速。风险为本指南 R76 / R77，历史风险与失败记录保留。

## 问题与修正

已有系统的入口仍容易将安装示例和旧组件作为通用优化，系统更新章节又单独提供裸 `apply`。本轮分开首次安装与维护提示词，新增 `10b-upstream-review-and-update.md`：版本识别、上游适用范围、保留数据、更新范围、匹配资源 / 签名、回退和分层验收依次完成。旧稳定性包明确只适用于固定基线，并说明 `--check` 的覆盖边界与 fw4 / SIPA 的区别。

核对 v2026.10.27.2 的发布提交、发行说明与资产 API digest，记录 Wi-Fi 5.4 TX 移植、日志降噪、主线 SIPA 忙时重试和构建保护的区别。`ret -115` 按上游解释为通常正常的 IPA 恢复流控，以实际通信与新增错误判断故障；静音日志不等于故障消失。

`versions.json` 保留原安装版本、资产 SHA256、运行系统与旧组件来源；新增独立 `upstream_review`。候选版状态为 `reviewed_not_device_upgrade_tested`，不晋升已验证基线。资产 digest 是 GitHub API 元数据，未下载内核 / rootfs，也未完成发行签名验证。
