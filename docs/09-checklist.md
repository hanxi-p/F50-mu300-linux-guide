# 9. 分阶段核对表

用于按顺序完成自己的刷机记录。勾选依据是实际输出，不是本指南描述过别人成功。

## 准备与降级

- [ ] 型号 / PCB 与工具支持相符，数据线和供电稳定。
- [ ] 电脑互联网走主路由，F50 接口已正确识别。
- [ ] 本机原始分区表、槽位、启动链、NV / 校准数据保存到两处。
- [ ] 用户文件另存，知道降级清空 userdata。
- [ ] B09 和工程 U-Boot 来源与 SHA256 一致。
- [ ] 降级工具成功退出，关键镜像读回匹配。
- [ ] Android B09 正常开机、槽位符合预期、USB 调试重新开启。

## 解锁与 Root

- [ ] 配套工程 U-Boot 写入正确槽、读回核对；本机原始 SPL 保留。
- [ ] subut 显示 Unlocked，Android 属性独立确认。
- [ ] 用本机对应 B09 原始 boot 修补，保存自己修补输出与哈希。
- [ ] 官方 Magisk 管理器完成环境安装与 Shell 授权。
- [ ] `adb shell su -c id` 实际返回 uid=0。

## SD 原生 OpenWrt

- [ ] 安装器 Check 的 SD 容量 / 来源正确。
- [ ] 选择 SD / openwrt-luci / 目标内核，核对格式化与写入摘要。
- [ ] 安装成功标志与读回校验完成。
- [ ] 根文件系统确实来自 SD。
- [ ] SSH、LuCI、Wi-Fi、蜂窝 WAN 可用。
- [ ] Linux 启动成功确认，失败计数为 0。
- [ ] 重启与断电接电启动恢复正常。

## 配置、切换与备份

- [ ] root 管理密码已设置为自己的密码，新密码能登录 LuCI；Wi-Fi 密码单独设置。
- [ ] 新管理地址、MU300 LAN 文件、USB 租约同步。
- [ ] 新地址 SSH 密钥连接正确，主机指纹已核对。
- [ ] 电脑 IPv4 / IPv6 默认路由仍符合自己联网安排。
- [ ] 知道 Linux 去 Android、Android 回 Linux 的命令和各自管理地址。
- [ ] 知道无 SD 原版回退约 300 秒，不在运行中拔卡。
- [ ] 完整 WRT 持久文件系统和启动恢复数据已保存、哈希可读。
- [ ] 私有备份不在公共仓库，恢复目标与适用边界明确。

## 安装后优化

安装后优化的逐项清单见 [密码、SSH、后台、性能、管理与备份](10a-post-install-optimization.md)。

- [ ] 按安装后优化入口核对系统稳定性配套组件；基础 rootfs 与组件版本分别记录。
- [ ] 5.4 流量卸载为 0；已启用的短信、IPv6 与管理服务通过验收。

## 可选扩展（按用户需求）

已有系统维护或升级时，另按[上游修正与更新](10b-upstream-review-and-update.md)检查：

- [ ] 已验证基线、目标 release、源码提交与配套模块分别记录，main 后续提交没有误标为发行版内容。
- [ ] 修改前备份可校验；面板、认证、配置与有效历史的保留 / 迁移范围明确。
- [ ] 下载上传与日志增量按实际场景验收，正常 `ret -115` 未单独判为传输故障；未测项单列。
- [ ] 维护只修改必要内容，当前网络、性能与加速配置保持既定设置；未重新应用首次安装默认值。

- [ ] 需要增加软件时，从 Q&A 进入对应说明，核对配置与自启。
- [ ] 调整性能参数时，保存原配置并核对目标场景中的效果。
- [ ] 修改 IPv6 LAN 时，客户端路由符合该使用场景。
